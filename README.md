# Practical Assignment #1 — Surface Rendering

## 📘 Description
This repository contains the implementation of **Practical Assignment #1** for the course VGGI.
The topic of the task is **Surface Rendering**, which involves creating and displaying a 3D surface using appropriate rendering techniques.

## 🔢 Variant
**Variant №12:**  
**Monge Surface with a Cylindrical Directrix Surface and with a Sinusoid as Meridian.**
